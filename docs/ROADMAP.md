# Roadmap

## Direção do projeto

Saturno evolui com foco em três frentes:

1. Planejamento e execução de sprint com maior previsibilidade.
2. Integrações técnicas com ecossistemas externos.
3. Operação self-hosted simples e segura.

## Prioridades de curto prazo

- expandir documentação de API
- ampliar cobertura de testes E2E
- melhorar trilha de onboarding técnico

## Prioridades de médio prazo

- fortalecer automações de integração
- evoluir observabilidade operacional
- padronizar guias de migração entre versões
