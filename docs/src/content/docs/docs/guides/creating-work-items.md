---
title: Criando Work Items
description: Boas práticas para modelar itens executáveis.
---

Work items devem ser pequenos, rastreáveis e orientados a entrega.

## Estrutura recomendada

- **Título**: objetivo claro e verificável.
- **Descrição**: contexto técnico e critérios de aceite.
- **Prioridade**: impacto no sprint.
- **Responsável**: dono da execução.

## Modelo de descrição

```md
Contexto:
Critérios de aceite:
Dependências:
Risco:
```

## Checklist de qualidade

- item executável em até poucos dias
- impacto e valor definidos
- dependências identificadas
- status atualizado no board
