Planejamento de sprint deve refletir capacidade real da equipe e prioridades do ciclo.

## Fluxo recomendado

1. Definir período da sprint.
2. Configurar capacidade por membro.
3. Priorizar work items por impacto.
4. Confirmar dependências e riscos.
