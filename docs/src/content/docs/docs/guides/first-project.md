title: Primeiro Projeto
description: Estruture a primeira organização, equipe e sprint.
---

## 1. Criar organização

Acesse o painel inicial e registre a organização que representará sua operação.

## 2. Criar equipe

Associe membros à equipe e defina responsabilidades iniciais.

## 3. Abrir sprint inicial

Defina:

- data de início e término
- capacidade da sprint
- objetivos técnicos principais

## 4. Carregar backlog inicial

Cadastre itens com prioridade e esforço estimado.

## 5. Iniciar execução

Use board e calendário para acompanhar progresso e bloqueios.
