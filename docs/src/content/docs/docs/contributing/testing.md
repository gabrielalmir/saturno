---
title: Testes
description: Estratégia de testes para backend e frontend.
---

## Testes de backend

```bash
composer test
```

## Testes E2E

```bash
npm run test:e2e
```

## Execução interativa de E2E

```bash
npm run test:e2e:ui
```

## Critério mínimo para PR

- testes relevantes passando
- lint e type checking sem erro
- descrição clara do comportamento alterado
