## Stack principal

- Backend: Laravel (PHP)
- Frontend: React + TypeScript
- Banco: SQLite ou PostgreSQL
- Build: Vite

## Blocos funcionais

- gestão de organizações e equipes
- planejamento de sprint e capacidade
- execução e tracking de work items
- integração com serviços externos

## Diretriz de evolução

Mudanças arquiteturais devem preservar simplicidade operacional, rastreabilidade e capacidade de self-hosting.
