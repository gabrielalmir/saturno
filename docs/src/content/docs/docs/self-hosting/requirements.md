## Requisitos de infraestrutura

- 2 vCPU
- 4 GB RAM
- 20 GB de disco

## Dependências de runtime

- Docker 24+ e Docker Compose
- ou PHP 8.2+, Composer 2, Node.js 18+, PostgreSQL 15+

## Rede e segurança

- domínio público com TLS
- firewall com portas mínimas expostas
- backup recorrente de banco
